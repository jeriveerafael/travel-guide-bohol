# Bohol destination map reference points

Coordinates are stored in decimal degrees (latitude, longitude; WGS84-style map coordinates) and used directly to place Flutter Map markers. These are intended as practical visitor-area map pins, not property-boundary or survey-grade coordinates. Check them visually against local signage or operators before using them for navigation.

## Reference notes

- Chocolate Hills Complex / Carmen location: Google Maps place listing and Behold Bohol municipal destination information.
- Tarsier Sanctuary: official tourism listing gives the Corella / Canapnapan visitor location; map point cross-checked with geotagged sanctuary-area image/map references.
- Loboc River Cruise: OpenStreetMap tourism / river-cruise point near the Loboc riverfront.
- Hinagdanan Cave: mapped cave visitor-site coordinates.
- Baclayon Church: front-door / church-entrance GPS reference.
- Alona Beach: mapped beachfront-area reference.
- Blood Compact Shrine: mapped Bool shrine-area reference.
- Anda: Quinale White Beach map reference.
- Dumaluan: geotagged beach photograph metadata at Dumaluan Resort.

An entire island or municipality does not have one single exact coordinate. For that reason the broad Panglao Island seed record has been relabelled as Dumaluan Beach and points to the beach area represented by its photo.
